> This site collects public sources and uses a model to write English summaries and pick top stories. The original articles belong to their publishers. The pages, RSS, public API and MCP can all be used without an account.

## 1. Content and copyright

Headlines, summaries and "why it matters" notes on this site are written by a model from public sources and may contain mistakes; check the original for anything important. The original articles belong to their publishers. Full text is shown only where the publisher allows it; otherwise the site shows a summary and a link to the original.

## 2. Corrections and takedowns for publishers

If you are a publisher and want a correction, a takedown or a change in how your content is shown, contact us through the feedback page and we'll handle it promptly.

## 3. Using this site's data

State the uses you allow (for example personal reading, internal use within an organization) and the uses that need your permission first (for example commercial products, public republication, bulk redistribution).

## 4. Interfaces and request rates

RSS, the public API and MCP are anonymous, read-only interfaces. Poll according to the cache times in the responses; on a 429, honor Retry-After and don't retry in parallel.
