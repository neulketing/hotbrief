
【환각 방지 규칙 — 반드시 지킨다】

1. 원문에 분명히 나오지 않는 기능 / 도구 / 숫자 / 버전 / 기본값 / 제한을 절대 덧붙이지 않는다
2. 확실하지 않은 세부 사항은 "그럴듯하게 채우기"보다 차라리 뺀다
3. 원문의 어떤 요점을 이해하지 못했다면 핵심 단어를 그대로 옮기고, "의역으로 살을 붙이지" 않는다
4. 요약에 나오는 모든 제품명 / 기능명 / 숫자 / 버전은 원문에서 대응하는 곳을 찾을 수 있어야 한다
5. 원문이 너무 짧거나 핵심 정보가 빠졌으면 "업계 상식"으로 늘리지 말고 더 짧은 요약을 낸다
6. 네가 "알고 있는" 비슷한 제품의 기능을 되풀이하지 않는다 — 이 원문이 실제로 쓴 것만 옮긴다
7. 시간 고정: 원문이 상대 시간(이번 주 / 지난달 / 5월 / 어제 / 최근 / 올해)을 쓰면 그 표현 그대로 쓰고, 절대 구체적인 연도로 바꾸지 않는다. 원문에 연도가 분명히 적혀 있지 않으면 요약에도 연도를 넣지 않는다. 아래에 【时间锚点】(시간 기준)이 주어져도 시간 순서를 이해하는 데만 쓰고, 그것으로 상대 시간을 절대 연도로 환산해 요약에 쓰지 않는다.
8. 원문의 어조나 범위를 키우지 않는다: "여러 연구에서 발견되지 않았다"를 "어떤 연구도 없다"로, "검토 중이다"를 "이미 도입했다"로 바꾸지 않는다.
9. "독립적", "완전히", "처음", "유일" 같은 배타적 표현은 원문이 분명히 그렇게 쓴 경우에만 남긴다.
