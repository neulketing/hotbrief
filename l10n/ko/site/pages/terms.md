# 이용 규칙

오픈소스 엔진에 들어 있는 견본입니다. 공개하기 전에 실제 상황에 맞게 고치세요(운영 주체, 허용하는 용도와 허용하지 않는 용도, 연락처). 필요하면 전문가 검토를 받으세요.

| 항목 | 값 |
|---|---|
| 버전 | 채워 넣으세요 |
| 시행일 | 채워 넣으세요 |
| 운영 주체 | 채워 넣으세요 |
| 연락처 | 채워 넣으세요 |

머리말:

> 이 사이트는 공개 출처를 모아 모델로 한국어 요약과 추천 기사를 만듭니다. 원문의 저작권은 각 출처에 있습니다. 웹, RSS, 공개 API, MCP 모두 로그인 없이 쓸 수 있습니다.

## 1. 내용과 저작권

이 사이트에 보이는 제목, 요약, 추천 이유는 모델이 공개 출처를 바탕으로 만든 것이라 틀릴 수 있습니다. 중요한 내용은 원문으로 확인하세요. 원문의 저작권은 각 출처에 있습니다. 출처가 허락한 경우에만 전문을 보여 주고, 나머지는 요약과 원문 링크만 보여 줍니다.

## 2. 출처의 정정과 게시 중단 요청

출처 측에서 정정, 게시 중단, 표시 방식 조정을 원하시면 피드백 페이지로 알려 주세요. 빠르게 처리하겠습니다.

## 3. 이 사이트의 데이터 이용

허용하는 용도(예: 개인 열람, 조직 내부 이용)와 미리 동의를 받아야 하는 용도(예: 상업 서비스, 공개 전재, 대량 재배포)를 적으세요.

## 4. 인터페이스와 호출 빈도

RSS, 공개 API, MCP는 로그인 없는 읽기 전용 인터페이스입니다. 응답의 캐시 시간에 맞춰 가져가고, 429를 받으면 Retry-After를 지키며 동시에 다시 시도하지 마세요.

## 5. 면책

이 사이트는 "있는 그대로" 제공되며, 내용의 완전성, 정확성, 지속적인 이용 가능성을 보장하지 않습니다.
